隱私權政策

最後更新：2026 年 10 月 8 日

本政策說明 WG小工具（https://karzeworks.github.io/，以下稱「本站」）如何處理你的資料。使用本站即表示你同意本政策。

你輸入的資料

你在計算機中輸入的日期、LTD、MTD 與目標業績，只會在你的瀏覽器中計算，並以瀏覽器的 localStorage 儲存在你自己的裝置上，方便下次使用。這些資料不會傳送到本站或任何伺服器。你可以隨時清除瀏覽器的網站資料來刪除它們。

廣告與 Cookie

本站使用 Google AdSense 顯示廣告。Google 等第三方供應商會使用 Cookie，根據使用者先前造訪本站或其他網站的紀錄來放送廣告。

  • Google 使用廣告 Cookie，讓 Google 及其合作夥伴能根據使用者造訪本站和/或網際網路上其他網站的情況放送廣告。
  • 你可以前往 Google 廣告設定 停用個人化廣告，或前往 www.aboutads.info 停用第三方供應商的個人化廣告 Cookie。
  • 關於 Google 如何使用資料，請參閱 Google 如何使用合作夥伴網站或應用程式的資訊。

網站代管

本站由 GitHub Pages 代管。GitHub 可能為了安全與維運目的記錄存取資訊（例如 IP 位址），詳見 GitHub 隱私權聲明。

兒童隱私

本站並非以 13 歲以下兒童為對象，也不會刻意蒐集兒童的個人資料。

政策變更

本政策若有修改，會更新於本頁並調整上方的「最後更新」日期。

聯絡方式

對本政策有任何疑問，請透過 GitHub Issues 與我們聯絡。
